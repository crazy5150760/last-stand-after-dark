# Restructuring phone checklist — Alpha 0.86, unchanged gameplay

Device: Samsung S21 Ultra / Brave. Keep a JSON backup first. Use the existing
HTTPS game or the validated candidate when a new review URL is actually deployed.
No new update/version label is expected: the production bytes/build ID are equal.
The root repository index.html is a template; it is not the file to open directly.

- [ ] Open the menu in portrait and landscape. Same title art, Play/Journal/
  Settings, previews and readable layout; no blank/missing art or loading failure.
- [ ] Start a normal run. Move, aim/fire automatically and Dash. Keep holding the
  joystick and press Pause with a second finger; the game must pause immediately.
  Resume, use phone Back through menus, rotate and background/return safely.
- [ ] Take the first upgrade without rushed/automatic selection. Confirm familiar
  weapon choices, upgrades/evolutions, enemy art/animation and hit behavior.
- [ ] Use Developer Training to visit Breaker, Warden, Harvester and specialists.
  Confirm the same attacks, shield behavior and training isolation; no need to
  spend a valuable natural run reaching every boss.
- [ ] Check fuel/shock/barricades, salvage and supplies as encountered. Reach the
  three-minute exit when practical; finish to held run stats. Optional overtime,
  survivor rescue and returning through the exit should behave as before.
- [ ] Open Pause audio controls: effects/music/master settings still respond.
  Back/Resume keep time frozen while menus or upgrade/results screens are open.
- [ ] Check best time, journal, presets and settings before/after closing. Export
  and review a backup; import only if deliberately testing isolated/safe storage.
  Do not overwrite existing good records just to complete this checklist.
- [ ] At the normal HTTPS install/ address, verify offline readiness. Finish/close
  game/setup windows, enable airplane mode, reopen and play; reconnect afterward.
  No forced reload and no invented new waiting Alpha version should appear.
- [ ] Compare a familiar crowded scene with the prior build: visible movement,
  touch response and frame pacing should feel the same. Report orientation,
  elapsed time, enemy load and heat if different. VM test timings are not FPS.

Actual phone results, natural balance, high-refresh/thermal performance, audio
perception, storage durability and Android operating-system events remain owner
test gates. No checkbox is pre-marked based on mock/byte-comparison evidence.
