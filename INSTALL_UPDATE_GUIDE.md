# Installation and updates

The existing public game is https://crazy5150760.github.io/last-stand-after-dark/ .
Open its install/ page for the current installation/update controls. Keep JSON
backups before moving browsers or origins. A downloaded worker waits until the
old clients close; do not force activation during a run. Brave may require Force
stop after finishing and closing all game/setup windows. Active runs do not
survive closing the app.

This restructuring does not change the game bytes, version, manifest, save keys,
worker lifecycle or offline build ID. It deliberately produces no new update.
See docs/DEPLOYMENT.md and docs/MANUAL_TEST.md. Earlier notes remain unchanged in
docs/history/INSTALL_UPDATE_GUIDE.md.
