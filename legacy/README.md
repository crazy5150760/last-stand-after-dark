# Protected releases

alpha-0.86/index.html and game.js preserve the latest published/CI-verified
release exactly. preservation.json and source-inventory.json document provenance
and every original source-file hash. Never edit these reference bytes to repair a
new-build test. All original art and metadata are retained under assets/ with a
hash map; original Alpha 0.82 HTML remains at repository root.

Latest published does not mean latest separately phone-accepted: the owner
explicitly accepted Alpha 0.85; separate Alpha 0.86 phone acceptance is unrecorded.
The earlier local/remote Alpha branches remain intact. Historical documentation
is under docs/history and may describe already-completed approval/install steps.
